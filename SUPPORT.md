# Getting help

Thanks for using nl6. Here's where to go depending on what you need.

## Documentation first

- **[README](README.md)** — what nl6 is, quick start, and links out.
- **[Documentation site](https://labmonkeys-space.github.io/nl6/)** — flags,
  protocols, load-test scenarios, and runbooks.
- **[CLAUDE.md](CLAUDE.md)** — the full build/run/architecture reference.

## Questions and usage help

Open a [GitHub issue](https://github.com/labmonkeys-space/nl6/issues/new/choose)
using the **Question** template (or apply the `question` label). Please include
your nl6 version (`nl6 -version`), platform, and the exact command you ran — it
makes a fast answer far more likely.

## Bugs and feature requests

- **Bug?** Open a [bug report](https://github.com/labmonkeys-space/nl6/issues/new/choose).
- **Idea or missing capability?** Open an
  [enhancement request](https://github.com/labmonkeys-space/nl6/issues/new/choose).

See [CONTRIBUTING.md](CONTRIBUTING.md) if you'd like to send a change yourself.

## Security issues

**Do not** open a public issue for vulnerabilities. Follow the private
disclosure process in [SECURITY.md](SECURITY.md).

## Response expectations

nl6 is maintained on a best-effort basis. There is no SLA — please be patient
and avoid pinging; a clear, reproducible report is the best way to get a timely
response.
