quick start

build from source · install a package · or pull with docker
01 · clonegit
$git clone https://github.com/labmonkeys-space/nl6.git
$cd nl6
02 · buildmake · go 1.26+
$make tidy
$make build
03 · runneeds root
$sudo ./go/nl6/nl6 -auto-start-ip 10.0.0.1 -auto-count 100
or install a package
01 · download & install.deb / .rpm · from releases
$curl -LO https://github.com/labmonkeys-space/nl6/releases/download/v0.29.0/nl6_0.29.0_amd64.deb
$sudo apt install ./nl6_0.29.0_amd64.deb
$curl -LO https://github.com/labmonkeys-space/nl6/releases/download/v0.29.0/nl6-0.29.0-1.x86_64.rpm
$sudo dnf install ./nl6-0.29.0-1.x86_64.rpm
02 · configure & startsystemd · needs root
$sudoedit /etc/nl6/nl6.conf
$sudo systemctl enable --now nl6
or on nixos · declarative flake
01 · enable the moduleservices.nl6
#services.nl6.enable = true;
02 · prebuilt cachenix.settings · no cli
#substituters = [ "https://nl6.cachix.org" ];
#trusted-public-keys = [ "nl6.cachix.org-1:nfaq8JEbMcARjzc/oPyNIrcQrXKe13phUtMg0RucnLA=" ];
or with docker
01 · pullno toolchain
$docker pull ghcr.io/labmonkeys-space/nl6:latest
02 · runneeds --cap-add=net_admin
$docker run --rm -it \ --cap-add=NET_ADMIN \ --device=/dev/net/tun \ --network=host \ ghcr.io/labmonkeys-space/nl6:latest \ -auto-start-ip 10.0.0.1 -auto-count 100

what's in the box

six pillars
01
30,000 devices

Tested scale on a single host. Parallel TUN pre-allocation, lock-free sync.Map for O(1) OID lookups, pre-computed next-OID mappings.

02
Protocols

SNMP v2c/v3 (MD5/SHA1 · DES/AES128), SSH with VT100, HTTPS REST, NetFlow v5 / v9 / IPFIX, gNMI (OpenConfig interfaces). sFlow v5 (experimental). Push exporters: SNMP traps/informs, syslog, gNMI dial-out.

03
Load-test fidelity

Arm → run a bounded push experiment over 7 protocols → get an exact sent-ledger. Diff it against your monitor to localize missed or duplicated telemetry. Fidelity mode, loss localization, run tagging, nl6-reconcile CLI, HTML report.

04
28 device types

Routers, switches, firewalls, servers, GPU servers (DGX/HGX), storage systems, Linux servers — across 8 categories.

05
GPU simulation

NVIDIA DGX-A100 / H100 / HGX-H200 with per-GPU DCGM OIDs — utilization, VRAM, temp, power, fan, SM/memory clocks.

06
Namespace isolation

Each device runs in the dedicated nl6sim network namespace with its own TUN interface and IP.

07
Dynamic metrics

100-point sine-wave cycling for CPU, memory, temperature; full IF-MIB counter set (octets, ucast / mcast / bcast packets, errors, discards) with per-device error scenarios; per-GPU DCGM OIDs.
