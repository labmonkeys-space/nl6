Architecture

nl6 is a single Go program that stands up thousands of simulated devices inside a dedicated Linux network namespace. Each simulated device has its own IP address on a TUN interface, its own SNMP listener, its own SSH server, a gNMI server, and, for storage devices, its own HTTPS REST endpoint.

System overview​

The diagram is a C4 container view rendered as a Mermaid flowchart. It shows what lives inside the nl6 process, the host-side Linux infrastructure it depends on, and how operators and monitoring systems reach it.

The namespace was opensim before the fork was renamed; see Network namespace for the one-time cleanup.

gNMI and NETCONF both carry YANG-modelled data, OpenConfig or a vendor's native model. SSH appears twice because NETCONF reuses it as a transport: the same login and host key, a different subsystem, a different port.

Scope​

  • gNMI dial-in: Capabilities, Get and Subscribe in SAMPLE, ON_CHANGE and ONCE mode over /interfaces and /components. cisco_asr9902 and juniper_mx10004 add a per-type catalogue with native origins. See gNMI dial-in.
  • gNMI dial-out: the dial-in payload pushed to a collector over Arista gnmireverse, dropped on outage. See gNMI dial-out.
  • NETCONF: the IOS XE draft establish-subscription with push-update and push-change-update on interface state. No get, no edit-config, no RFC 8639. See NETCONF.

Key design decisions​

ChoiceGainedGiven up
sync.Map for OID lookupsLock-free O(1) reads under concurrent SNMP loadSimple iteration; walks need the pre-computed next-OID map
Pre-computed next-OID mappingsGETNEXT and WALK without scanning the tableMemory per loaded device type
Buffer pool on the SNMP pathLess GC pressure at high request ratesEvery handler path must return its buffer to the pool
Shared SSH and TLS keys across all devicesNo per-device key generation, so 30,000 devices start in minutesEvery device presents the same host key and certificate; nl6 does not model PKI
Analytic IF-MIB countersEvery ifTable and ifXTable counter is computed on demand from a per-direction sine wave, with no polling loopTraffic shapes other than the sine wave. See SNMP
Network namespace isolationThe nl6sim namespace keeps systemd-networkd off the TUN interfacesLinux only, and root is required
Per-device flow egressA FORWARD -i veth-sim-host -j ACCEPT rule lets per-device exporters send out of the namespace on Docker hosts that default FORWARD to DROPAn iptables dependency in the image; the rule is removed in NetNamespace.Close

Container image​

The simulator is published as ghcr.io/labmonkeys-space/nl6. ci.yml publishes on push to main; release.yml publishes on a release tag. See Docker to run it.
