# nl6 role

Installs nl6 from the native release package, verified against the release `checksums.txt`, and runs the packaged `nl6.service`.
Targets Ubuntu 24.04 and 26.04 on amd64 and arm64.

For the variables, an example play and what to know before running it, see [Install with Ansible](https://nl6.eu/getting-started/ansible).
